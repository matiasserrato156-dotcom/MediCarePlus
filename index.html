Confirma y guarda

Transparencia

Política de tratamiento de datos

Versión simulada · proyecto académico ADSO

Este texto es una simulación académica. No constituye una política legal real ni debe usarse con datos de salud verdaderos.

1. Qué datos recibe la demostración

El formulario de agenda solicita nombre completo, documento, teléfono y correo electrónico. Estos datos se guardan únicamente en el localStorage de tu navegador y se usan para mostrar el resumen de la cita y la lista de “Mis citas”.

2. Dónde se almacenan

La información permanece en tu dispositivo bajo la clave medicareplus.citas.v1. No se envía a un servidor, no se comparte con terceros y no se utiliza para publicidad. Si borras los datos del navegador, las citas desaparecen.

3. Datos que no debes ingresar

No ingreses información clínica, diagnósticos, datos de menores ni documentos reales. Utiliza datos inventados para probar la experiencia.

4. Seguridad

localStorage no es un almacenamiento seguro ni cifrado. Cualquier persona con acceso al navegador podría leerlo. Por eso el proyecto no debe usarse para gestionar citas reales.

5. Tus derechos

Puedes eliminar la información en cualquier momento desde la configuración de tu navegador. Al no existir un servidor, no hay un canal de solicitudes formales ni responsables de tratamiento reales.

6. Contacto de la demostración

Las dudas sobre el proyecto académico pueden dirigirse al correo ficticio hola@medicareplus.demo. No se atienden solicitudes médicas.
